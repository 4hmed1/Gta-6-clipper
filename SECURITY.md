# Security Policy

## Supported versions
Only the latest release is actively supported for security fixes.

## Reporting a vulnerability
If you find a security vulnerability, please do **not** open a public issue.
Instead, email the maintainers with a description of the issue, steps to
reproduce, and the potential impact. We will acknowledge receipt within 72 hours.

## What this app does
Max Clipper runs 100% locally on your machine. It does not upload anything
to a server. It does not phone home. It does not use any LLM or paid API in
clip selection. If you find something that contradicts this, that is a bug and
we want to know.

## Scope
This covers the MaxClipper codebase. It does not cover vulnerabilities in
third-party dependencies (yt-dlp, FFmpeg, Python, etc.). Report those to the
respective projects.
