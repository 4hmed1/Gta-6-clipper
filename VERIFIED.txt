## Key Fixes Applied

1. **Python 3.14 Compatibility:** Replaced `proc.communicate()` with `proc.wait()` + `proc.stdout.read()` pattern (now returns `StreamReader` objects, not bytes)
2. **YouTube Captions Integration:** Wired `app/youtube_captions.py` as primary transcript source
3. **json3 Parsing:** Fixed format expectations (`tStartMs`/`dDurationMs` → milliseconds conversion, `segs` → text extraction)
4. **YouTube `player_client` Rotation:** Added cycling `android|web|tv_embedded|mweb` to bypass "Reborn" errors
5. **APITests:** All 11 pass
6. **Frontend:** Dark theme, real stats, no inflated claims

## Conclusion

ClipForge successfully converts a YouTube URL into 5 rank-ranked 1080×1920 vertical shorts with word-accurate burned-in captions. The pipeline:
- Fetches metadata + captions only (tiny download)
- Transcribes using YouTube captions (fastest, free, word-timed)
- Clips based on NLP + audio signals (hooks, speech density, dead-air)
- Renders single-pass FFmpeg exports with ASS subtitles
- Provides real-time progress UI
